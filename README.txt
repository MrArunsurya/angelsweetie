VERSION 2 — CINEMATIC BIRTHDAY WEBSITE
========================================
Open index.html in Chrome/Edge.

Highlights:
• Netflix/Apple-style cinematic full-screen sections
• 3D-ish floating/rotating memory photos
• Film-grain overlay
• Mouse-following parallax on desktop
• Scroll-controlled animated timeline
• Horizontal memory reel on desktop
• Swipe-friendly memory reel on mobile
• Responsive/autofit images using object-fit:cover
• Generated birthday melody using Web Audio (no MP3 required)
• Final "Happy Birthday Angel & Sweetie" reveal
• Celebration particles
• prefers-reduced-motion support

To use custom music later:
Replace the Web Audio melody in the script with an MP3/audio element if desired.
